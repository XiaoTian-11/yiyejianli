# 壹页简历 — 运行与部署

本项目包含运行壹页简历应用所需的一切。

在线体验: https://zhijianli.ai

完整部署说明：请阅读 [docs/壹页简历部署手册.md](docs/壹页简历部署手册.md)。

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `DEEPSEEK_API_KEY` in [.env.local](.env.local) to your DeepSeek API key
3. Run the app:
   `npm run dev`
