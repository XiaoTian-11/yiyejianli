## 1. 现状概述

### 1.1 当前实现

当前支付功能为**前端模拟实现**，不具备真实的支付能力：

- **支付触发点：**
  - 定价页面 ([PricingPage.tsx](../src/pages/PricingPage.tsx)) → 选择方案
  - 升级弹窗 ([UpgradeModal.tsx](../src/components/UpgradeModal.tsx)) → 功能受限时弹出
  - 支付页面 ([PaymentPage.tsx](../src/components/PaymentPage.tsx)) → 模拟支付流程

- **当前流程：**
  ```
  选择方案 → 选择支付方式(微信/支付宝) → 点击支付按钮
  → 2秒模拟处理 → 前端状态更新为 member → 跳转仪表盘
  ```

- **关键代码位置：**
  - `src/components/PaymentPage.tsx` — 支付页面 UI（微信/支付宝选择 + 模拟处理）
  - `src/components/UpgradeModal.tsx` — 升级弹窗（方案选择 + 模拟二维码 + 模拟确认）
  - `src/App.tsx:371-383` — 支付成功回调（更新内存中的用户层级）
  - `src/constants.ts:177-227` — 定价方案定义

### 1.2 需要改造的部分

| 组件 | 当前行为 | 需改造为 |
|------|---------|---------|
| `PaymentPage.tsx` | `setTimeout` 模拟 2 秒后调 `onSuccess()` | 调用后端创建订单 API，展示真实二维码/跳转支付 |

| `App.tsx` 成功回调 | 仅更新前端内存状态 | 调用后端验证支付状态 API，同步用户会员信息 |

### 4.3 权限检查逻辑

```typescript
// 判断是否为会员（含过期检查）
function isMember(user: AppUser): boolean {
  if (user.tier !== 'member') return false;
  if (user.memberUntil) {
    return new Date(user.memberUntil) > new Date();
  }
  return true;
}

// 检查功能权限
function canAccessPremiumTemplate(user: AppUser | null): boolean {
  return user !== null && isMember(user);
}

function canExportPDF(user: AppUser | null): boolean {
  if (!user) return false;
  if (isMember(user)) return true;
  return user.remainingPdfExports > 0;
}
```

```typescript
// POST /api/payment/create-order
// 使用微信支付 APIv3

import crypto from 'crypto';

interface CreateOrderRequest {
  planType: string;    // 方案类型
  userId: string;      // 用户 ID
}

interface CreateOrderResponse {
  orderId: string;
  codeUrl: string;     // 用于生成二维码的 URL
  qrCodeData: string;  // 可直接渲染的二维码数据
}

async function createWechatNativeOrder(req, res) {
  const { planType, userId } = req.body;
  const plan = PLANS.find(p => p.type === planType);
  
  if (!plan) {
    return res.status(400).json({ error: "无效的方案类型" });
  }

  // 生成商户订单号
  const outTradeNo = `WX${Date.now()}${Math.random().toString(36).substr(2, 8)}`;
  
  // 保存订单到数据库
  await saveOrder({
    orderId: outTradeNo,
    userId,
    planType,
    amount: plan.price,
    status: 'pending',
    createdAt: new Date()
  });

  // 调用微信支付 Native 下单 API
  const response = await fetch('https://api.mch.weixin.qq.com/v3/pay/transactions/native', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Accept': 'application/json',
      'Authorization': generateWXAuthorization('POST', '/v3/pay/transactions/native'),
    },
    body: JSON.stringify({
      appid: process.env.WECHAT_APPID,
      mchid: process.env.WECHAT_MCHID,
      description: `壹页简历 - ${plan.name}`,
      out_trade_no: outTradeNo,
      notify_url: `${process.env.APP_URL}/api/payment/notify/wechat`,
      amount: {
        total: Math.round(plan.price * 100), // 单位：分
        currency: 'CNY',
      },
      attach: JSON.stringify({ userId, planType }),
    }),
  });

  const result = await response.json();
  
  res.json({
    orderId: outTradeNo,
    codeUrl: result.code_url,
    qrCodeData: result.code_url,
  });
}

// POST /api/payment/notify/wechat
// 接收微信支付结果通知（需要验证签名）
async function handleWechatNotify(req, res) {
  const signature = req.headers['wechatpay-signature'];
  const timestamp = req.headers['wechatpay-timestamp'];
  const nonce = req.headers['wechatpay-nonce'];
  const serial = req.headers['wechatpay-serial'];
  
  // 1. 验证签名
  const verified = verifyWechatSignature(signature, timestamp, nonce, req.body);
  if (!verified) {
    return res.status(401).json({ code: 'FAIL', message: '签名验证失败' });
  }
  
  // 2. 解密通知内容
  const decrypted = decryptWechatNotify(req.body);
  const { out_trade_no, trade_state } = decrypted;
  
  // 3. 更新订单状态
  if (trade_state === 'SUCCESS') {
    await updateOrderStatus(out_trade_no, 'completed');
    const order = await getOrder(out_trade_no);
    await upgradeUserMembership(order.userId, order.planType);
  }
  
  // 4. 返回确认
  res.json({ code: 'SUCCESS', message: 'OK' });
}
```

### 5.4 前端轮询支付状态

```typescript
// 在 PaymentPage.tsx 中实现

function usePaymentPolling(orderId: string) {
  const [status, setStatus] = useState<'pending' | 'paid' | 'timeout'>('pending');
  
  useEffect(() => {
    if (!orderId) return;
    
    const POLL_INTERVAL = 2000;  // 每 2 秒轮询
    const POLL_TIMEOUT = 300000;  // 5 分钟超时
    const startTime = Date.now();
    
    const interval = setInterval(async () => {
      if (Date.now() - startTime > POLL_TIMEOUT) {
        clearInterval(interval);
        setStatus('timeout');
        return;
      }
      
      try {
        const res = await fetch(`/api/payment/query/${orderId}`);
        const data = await res.json();
        if (data.status === 'completed') {
          clearInterval(interval);
          setStatus('paid');
        }
      } catch (err) {
        console.error('轮询失败:', err);
      }
    }, POLL_INTERVAL);
    
    return () => clearInterval(interval);
  }, [orderId]);
  
  return status;
}
```

```typescript
// POST /api/payment/create-order (alipay)
async function createAlipayOrder(req, res) {
  const { planType, userId } = req.body;
  const plan = PLANS.find(p => p.type === planType);
  
  if (!plan) {
    return res.status(400).json({ error: "无效的方案类型" });
  }
  
  const outTradeNo = `ALI${Date.now()}${Math.random().toString(36).substr(2, 8)}`;
  
  await saveOrder({
    orderId: outTradeNo,
    userId,
    planType,
    amount: plan.price,
    status: 'pending',
    createdAt: new Date()
  });
  
  // 构建支付宝请求参数
  const params = {
    out_trade_no: outTradeNo,
    product_code: 'FAST_INSTANT_TRADE_PAY',
    total_amount: plan.price.toFixed(2),
    subject: `壹页简历 - ${plan.name}`,
    body: `购买${plan.name}，有效期${plan.type === 'lifetime' ? '永久' : plan.type}`,
    passback_params: encodeURIComponent(JSON.stringify({ userId, planType })),
    notify_url: `${process.env.APP_URL}/api/payment/notify/alipay`,
    return_url: `${process.env.APP_URL}/dashboard?payment=success`,
  };
  
  // 使用支付宝 SDK 生成支付页面
  const AlipaySdk = require('alipay-sdk').default;
  const alipay = new AlipaySdk({
    appId: process.env.ALIPAY_APP_ID,
    privateKey: process.env.ALIPAY_PRIVATE_KEY,
    alipayPublicKey: process.env.ALIPAY_PUBLIC_KEY,
    gateway: 'https://openapi.alipay.com/gateway.do',
  });
  
  const result = alipay.sdkExec('alipay.trade.page.pay', {
    method: 'alipay.trade.page.pay',
    bizContent: params,
    notifyUrl: params.notify_url,
    returnUrl: params.return_url,
  });
  
  // 返回支付页面 URL（在新窗口打开）或生成二维码 URL
  res.json({
    orderId: outTradeNo,
    paymentUrl: result,  // 直接打开的支付页面 URL
  });
}

// POST /api/payment/notify/alipay
async function handleAlipayNotify(req, res) {
  const verified = verifyAlipaySignature(req.body);
  if (!verified) {
    return res.send('fail');
  }
  
  const { out_trade_no, trade_status, total_amount } = req.body;
  
  if (trade_status === 'TRADE_SUCCESS' || trade_status === 'TRADE_FINISHED') {
    await updateOrderStatus(out_trade_no, 'completed');
    const order = await getOrder(out_trade_no);
    await upgradeUserMembership(order.userId, order.planType);
  }
  
  res.send('success');
}
```

## 7. 支付流程设计

### 7.1 完整支付流程

```
┌──────────────────────────────────────────────────────────────┐
│                     完整支付事务流程                           │
└──────────────────────────────────────────────────────────────┘

1. 用户点击「立即支付」
     │
     ▼
2. 前端 POST /api/payment/create-order
     │  { userId, planType, paymentMethod }
     │
     ▼
3. 后端创建订单
     │  - 生成订单号
     │  - 保存订单 (status: pending)
     │  - 调用支付网关 API
     │  - 返回 paymentUrl / codeUrl
     │
     ▼
4. 前端展示支付界面
     │  - 微信: 生成二维码 (使用 qrcode.js)
     │  - 支付宝: 新窗口打开支付页 或 生成二维码
     │  - 启动轮询 (每 2s 查询支付状态)
     │
     ▼
5. 用户完成支付
     │  - 微信: 扫码支付
     │  - 支付宝: 在新页面完成支付
     │
     ▼
6. 支付网关异步通知后端
     │  POST /api/payment/notify/{wechat|alipay}
     │  - 验证签名
     │  - 更新订单状态为 completed
     │  - 升级用户会员等级
     │
     ▼
7. 前端感知支付完成
     │  (二选一)
     ├─ 轮询检测: GET /api/payment/query/{orderId} → status=completed
     └─ 同步跳转: return_url 携带参数 → 前端检测
     │
     ▼
8. 前端展示支付成功
     │  - 更新用户状态 (tier: member)
     │  - 设置到期日
     │  - 跳转仪表盘
     │
     ▼
9. 完成
```

### 7.2 订单状态机

```
  pending ──────▶ paid ──────▶ completed
     │               │
     │               └──────────▶ refunded
     │
     └──────────▶ expired (超时未支付)
     │
     └──────────▶ cancelled (用户取消)
```

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // 简历集合
    match /resumes/{resumeId} {
      allow read, write: if request.auth != null 
                          && request.auth.uid == request.resource.data.userId;
      allow read, delete: if request.auth != null 
                           && request.auth.uid == resource.data.userId;
    }
    
    // 订单集合（新增）
    match /orders/{orderId} {
      allow read: if request.auth != null 
                   && request.auth.uid == resource.data.userId;
      allow create: if request.auth != null 
                     && request.auth.uid == request.resource.data.userId;
      // 禁止客户端直接修改/删除订单，仅允许服务端操作
      allow update, delete: if false;
    }
    
    // 用户集合（新增）
    match /users/{userId} {
      allow read: if request.auth != null 
                   && request.auth.uid == userId;
      // 禁止客户端直接修改，仅允许服务端操作
      allow write: if false;
    }
  }
}
```

## 10. 安全注意事项

### 10.1 密钥管理

| 原则 | 说明 |
|------|------|
| **永远不暴露在前端** | 所有支付密钥、商户号仅在服务端使用 |
| **环境变量隔离** | 开发/生产环境使用不同的支付密钥 |
| **证书轮换** | 定期更新 API 密钥和证书 |
| **Git 防护** | `.env` 文件已在 `.gitignore` 中，确保不提交密钥 |

### 10.2 签名验证

```
微信支付：使用 APIv3 签名规则，验证回调请求的真实性
支付宝：使用 RSA2 签名验证，确保通知来自支付宝服务器
总则：永远不要信任未验证签名的支付通知
```

### 10.3 幂等性

- 支付通知可能重复发送，订单状态更新必须实现幂等
- 使用订单号作为唯一键，防止重复处理
- 会员升级操作同样需要幂等保护

### 10.4 金额校验

```typescript
// 在支付通知处理中，必须验证金额一致性
if (notifyAmount !== orderAmount) {
  console.error(`金额不匹配: 通知${notifyAmount} vs 订单${orderAmount}`);
  return res.send('fail');
}
```

### 10.5 HTTPS

- 生产环境必须使用 HTTPS
- 支付回调 URL 必须为 HTTPS 地址
- Cloud Run 默认提供 HTTPS，无需额外配置
