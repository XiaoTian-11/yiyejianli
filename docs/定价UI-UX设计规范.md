## 1. 设计原则

### 1.1 定价页面核心原则

| 原则 | 说明 |
|------|------|
| **社会认同** | 突出「最受欢迎」标签，引导用户选择主推方案 |
| **价格锚定** | 单次导出 ¥5.9 作为锚点，衬托月卡的"超值" |
| **递进式展示** | 方案从左到右价格递增，形成心理对比 |
| **降低决策成本** | 明确标注日均价，将大额决策拆解为"每天不到 x 元" |
| **建立紧迫感** | 限时优惠标签、倒计时（可选） |

### 1.2 色彩体系

```
会员/付费相关颜色：
  - 主推色:   #2563eb (blue-600)  — 最受欢迎标签、CTA 按钮
  - 强调色:   #f59e0b (amber-500) — 皇冠图标、会员标识
  - 成功色:   #10b981 (emerald-500) — 购买成功
  - 免费色:   #64748b (slate-500)  — 免费功能标识
  - 高级色:   #8b5cf6 (violet-500) — 高级功能标识
  
背景:
  - 卡片背景: #ffffff
  - 高亮卡片阴影: rgba(37, 99, 235, 0.2)
  - 玻璃态: backdrop-filter: blur(12px)
```

## 6. 交互动效规范

### 6.1 使用现有动画体系

项目已集成 `motion/react`（Framer Motion），以下规范沿用现有模式：

### 6.2 定价页动效

| 元素 | 动效 | 参数 |
|------|------|------|
| 页面标题 | fade + slide up | `opacity: 0→1, y: 10→0, duration: 0.4` |
| 方案卡片 | stagger 入场 | `staggerChildren: 0.1, y: 20→0, scale: 0.95→1` |
| 最受欢迎标签 | pulse | `scale: [1, 1.05, 1], duration: 2, repeat: ∞` |
| 按钮 hover | scale + shadow | `scale: 1.05, shadow-lg` |
| 按钮 active | scale | `scale: 0.95` |

### 6.3 弹窗动效

| 元素 | 动效 | 参数 |
|------|------|------|
| 弹窗背景 | fade | `opacity: 0→0.6, duration: 0.2` |
| 弹窗内容 | scale + fade | `scale: 0.95→1, opacity: 0→1, duration: 0.3` |
| 步骤切换 | cross-fade | `opacity: 1→0, 0→1, duration: 0.2` |
| 成功勾 | scale + rotate | `scale: 0→1, rotate: -90→0, duration: 0.3` |
| 弹窗关闭 | scale + fade | `scale: 1→0.95, opacity: 1→0, duration: 0.2` |

### 6.4 状态过渡

```typescript
// 弹窗步骤切换 animation
const stepVariants = {
  enter: { opacity: 0, x: 20 },
  center: { opacity: 1, x: 0 },
  exit: { opacity: 0, x: -20 },
};

// 购买成功动画
const successIconVariants = {
  hidden: { scale: 0, rotate: -90 },
  visible: { 
    scale: 1, rotate: 0,
    transition: { type: "spring", stiffness: 200, damping: 15 }
  },
};
```

## 8. 响应式适配

| 断点 | 列数 | 卡片排列 |
|------|:----:|---------|
| `< 768px` (移动) | 1 列 | 垂直排列 |
| `768px - 1024px` (平板) | 2 列 | 2 × N 网格 |
| `> 1024px` (桌面) | 3 列（订阅）+ 1 行（单次） | 3 × N 网格 |
