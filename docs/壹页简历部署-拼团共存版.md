# 壹页简历部署 — 拼团共存版（云 Supabase 方案）

> **适用**：一台国内 2核2G ECS，已部署谷团宝拼团，现在加壹页简历
> **核心变化**：壹页简历**不再自托管 Supabase**（早期 2G 方案假设独占机器），改用**云 Supabase**（免费版，与拼团各自独立项目），服务器只多跑一个 Node 服务。2G 内存毫无压力。
> **关联**：[deploy/2g/](../deploy/2g/)（自托管 Supabase 版，仅当未来想省云库费用时参考）

---

## 1. 架构总览

```
用户浏览器
   │ HTTPS
   ▼
resume.xnkun.com ──► Nginx (443) ──► 127.0.0.1:3001（PM2: yiyejianli）
                                      ├─ 静态前端 dist/（含 /admin 管理后台）
                                      └─ /api/*（翻译/支付/订单）
                                      │
                                      └──► 云 Supabase（qrtujauyrdtgbtkzlvna，海外节点）
                                             ├─ PostgREST（users/orders 表，RLS）
                                             ├─ GoTrue（邮箱密码认证）
                                             └─ PostgreSQL（数据云托管）
```

与谷团宝共存关系：

| 服务 | 谷团宝（已上线） | 壹页简历（本次） |
|---|---|---|
| 域名 | gutuanbao.xnkun.com / admin.gutuanbao.xnkun.com | **resume.xnkun.com** |
| 后端端口 | 3000（PM2: gutuanbao-api） | **3001**（PM2: yiyejianli） |
| 数据库 | 云 Supabase（pooler 连接） | 云 Supabase（独立项目） |
| 静态托管 | Nginx 直接服务 | Node 服务托管（express.static） |
| 管理后台 | admin 子域名 | /admin 子路径 |

> ⚠️ 端口必须 3001（3000 已被拼团占用）。`server.ts` 已支持 `PORT` 环境变量。

## 3. 本地准备（只需一次）

### 3.1 确认 .env 完整

本机 `yiyejianli/.env` 已有：VITE_SUPABASE_URL / VITE_SUPABASE_ANON_KEY / SUPABASE_SERVICE_ROLE_KEY / PAYMENT_PROVIDER=mock / DEEPSEEK_API_KEY。

### 3.2 服务器 .env（单独维护）

```bash
# 服务器 /var/www/yiyejianli/.env —— 与本地 .env 内容一致（不含 VITE_* 构建变量也行，运行时读 secret）
# 首次部署时手动上传一次，之后 deploy.sh 不会覆盖它（tar 已排除 .env）
scp .env root@<服务器IP>:/var/www/yiyejianli/.env
```

> `VITE_SUPABASE_URL` 等构建变量已在本地构建时打进 bundle（`import.meta.env`），服务器 .env 只需运行时 secret：`SUPABASE_SERVICE_ROLE_KEY`、`DEEPSEEK_API_KEY`、`PAYMENT_PROVIDER`、`APP_URL` 等。直接把本地 .env 整份传上去最省事。

## 4. 服务器部署（一次性 + 每次发版）

### 4.1 首次：安装 Nginx 站点 + DNS

```bash
# 1. 域名控制台：resume.xnkun.com 加 A 记录 → 服务器公网 IP

# 2. 服务器上安装 Nginx 站点（用本仓库 deploy/resume/nginx-resume.conf）
#    先上传配置到服务器
scp deploy/resume/nginx-resume.conf root@<服务器IP>:/etc/nginx/sites-available/resume.conf

#    服务器上执行
ssh root@<服务器IP>
ln -s /etc/nginx/sites-available/resume.conf /etc/nginx/sites-enabled/resume.conf
nginx -t && systemctl reload nginx

# 3. 签发 HTTPS（certbot 已随拼团 init.sh 装好）
sudo certbot --nginx -d resume.xnkun.com
# 证书自动续期（certbot systemd timer）
```

> ⚠️ certbot 的 HTTP 验证需要 DNS 先生效（等 5~30 分钟）。

### 4.2 每次发版：一键部署

```bash
# 本机执行（自动：构建 → 上传 → 服务器 npm ci → pm2 重启 → 健康检查）
bash deploy/resume/deploy.sh <服务器IP> root
```

## 6. 运维

```bash
pm2 logs yiyejianli          # 日志（/var/www/yiyejianli/logs/）
pm2 restart yiyejianli       # 重启
pm2 status                   # 状态（max_memory_restart=400M 防泄漏）
free -h                      # 内存：2G + swap，跑两个 Node 服务 + Nginx 足够
```

**注意**：云 Supabase 免费项目约 7 天无请求会被暂停——`server.ts` 内置 keepalive（启动后 30s ping 一次，之后每 24h 一次），Node 服务在线即可保活。

## 7. 微信支付正式接入（备案后）

前置：已备案域名 + 微信商户号已开通。

1. **APP_URL**：`.env` 改为 `APP_URL="https://resume.xnkun.com"`（回调 notify_url 用）
2. **WECHAT_APPID**：填公众号/小程序 AppID
3. **平台公钥**：商户平台 → API安全 → 微信支付公钥 → 下载 `pub_key.pem` → 放入 `certs/wechatpay_pub.pem`
4. **切换**：`PAYMENT_PROVIDER=wechat`
5. 重启：`pm2 restart yiyejianli`

> 微信回调 `POST /api/payment/notify/wechat` 已由 server.ts 实现（验签 + 解密 + 幂等），Nginx 已反代 `/api/`。
