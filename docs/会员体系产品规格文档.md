## 1. 产品概述

### 1.1 产品定位

壹页简历面向求职者提供在线简历制作工具，采用 **Freemium + 订阅制** 商业模式：

- **免费层** — 提供基础简历编辑功能，限制导出能力，作为获客漏斗入口
- **付费层** — 通过会员订阅和单次导出两种方式实现商业变现

### 1.2 核心商业逻辑

```
免费用户（编辑体验无限制）→ 导出时遇到付费墙 → 选择单次导出或订阅会员
                                        ↓
                              会员用户持续使用 + 口碑传播
                                        ↓
                              续费 / 升级长期方案
```

**关键设计原则：** 编辑是体验核心，预览是编辑的一部分——不设限、不加水印。导出能力作为付费转化节点。

## 2. 用户分层与角色定义

### 2.1 层级总览

| 层级 | 类型标签 | 代码标识 | 说明 |
|------|----------|----------|------|
| `guest` | 未登录访客 | `'guest'` | 未注册/未登录用户，仅可浏览首页、模板列表和定价页 |
| `free` | 普通用户（免费） | `'free'` | 已注册登录，未付费。可创建和编辑简历，但不可导出 |
| `member` | 尊享会员 | `'member'` | 已付费订阅用户，解锁全部高级功能 |

### 2.2 用户状态转换

```
                      ┌─────────────┐
                      │   guest     │
                      │  (未登录)    │
                      └──────┬──────┘
                             │ 注册/登录
                             ▼
                      ┌─────────────┐
                 ┌─── │   free      │ ◄──── 会员过期自动降级
                 │    │  (免费用户)  │
                 │    └──────┬──────┘
                 │           │ 购买订阅方案
                 │           ▼
                 │    ┌─────────────┐
                 │    │   member    │
                 │    │  (尊享会员)  │
                 │    └─────────────┘
                 │           │
                 └───────────┘ 到期未续费
```

### 2.3 会员到期处理

| 场景 | 行为 |
|------|------|
| 会员到期日当天 | 不立即降级，保持 member 权益至当日结束 |
| 会员到期日次日 | 登录时检查 `memberUntil`，自动降级为 `free` |
| 降级影响 | 简历数据保留（不删除），仅锁住高级功能 |
| 重新订阅 | 恢复 member 状态，所有数据完整保留 |
| 终身卡 | `memberUntil` 设置为 `'2099-12-31'`，永不过期 |

## 4. 定价方案规格

### 4.1 方案一览

| 方案 | 类型标识 | 价格 | 日均价 | 定位 | 分类 |
|------|----------|:----:|:------:|------|:----:|
| **单次导出** | `single_export` | **¥5.9** | — | 临时需要导出一次 | `one_time` |
| **周卡会员** | `week` | ¥9.9 | 1.4 元/天 | 临时求职用户 | `subscription` |
| **月卡会员** | `month` | ¥15 | 0.5 元/天 | 短期求职用户（主推） | `subscription` |
| **季卡会员** | `quarter` | ¥36 | 0.4 元/天 | 跳槽季用户 | `subscription` |
| **年卡会员** | `year` | ¥99 | 0.27 元/天 | 职场新人（长期锁定） | `subscription` |
| **终身卡** | `lifetime` | ¥199 | — | 长期职场人士 | `subscription` |
| **学生年卡** | `student_year` | ¥49 | 0.13 元/天 | 在校学生 | `subscription` |

### 4.2 定价锚定策略

```
单次导出 ¥5.9  ← 锚点：让月卡 ¥15 显得"超值"（一次导出价 ≈ 月卡的 1/3）
      ↓
月卡 ¥15       ← 主推方案：比单次多 2 次就回本
      ↓
年卡 ¥99       ← 长期锁定：日均 ¥0.27 让用户觉得"不买就亏"
```

| 跨设备实时同步 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

### 4.4 单次导出设计要点

1. **不改变用户 `tier`** — 购买单次导出后，用户仍然是 `free` 层级
2. **增加导出次数** — `remainingPdfExports += 1`，导出后 `-1`
3. **导出的 PDF 无水印**
4. **不可累积多次购买** — 每次导出消耗一次，用完再买
5. **价格锚定** — ¥5.9 ≈ 月卡价格的 1/3，衬托月卡的"超值"

## 5. 用户流程

### 5.1 注册 → 免费用户路径

```
用户注册 → Supabase Auth 认证成功
  → 初始化 appUser（tier: 'free', remainingPdfExports: 0）
  → 进入 Dashboard
  → 选择模板创建简历
  → 在编辑器中自由编辑（无水印预览）
  → 点击"导出 PDF"
      → 检查 remainingPdfExports === 0
      → 弹出购买弹窗（导出拦截）
          ├─ 选择"单次导出 ¥5.9" → 支付 → remainingPdfExports = 1 → 导出
          └─ 选择"开通会员" → 跳转定价页 → 选择方案 → 支付
              → tier = 'member', remainingPdfExports = 999 → 无限导出
```

### 5.2 升级弹窗触发场景

| 触发原因 | `reason` 值 | 弹窗文案 |
|----------|-------------|----------|
| 点击 premium 模板 | `'templates'` | "此模板为会员专属，开通会员立即使用全部精美排版" |
| 简历数量达上限 5 份 | `'limit'` | "免费简历制作额度已满，开通尊享会员解锁 30 个版本上限" |
| 自定义板块达上限 3 个 | `'sections'` | "自定义板块数量达到限制，开通尊享会员解锁无限创意自定义板块" |
| 点击 ATS 检测 | `'ats'` | "ATS 高通过率检测与智能建议是会员专属的高级分析工具" |
| 点击导出（次数为 0） | `'export'` | "您当前没有导出次数，请选择以下方式继续" |

### 5.3 导出拦截弹窗特殊逻辑

导出拦截弹窗（ExportModal）与通用升级弹窗（UpgradeModal）**不同**，它提供两种选项：

```
┌──────────────────────────────────┐
│      📄 导出简历                  │
│                                  │
│  您当前没有导出次数               │
│                                  │
│  ┌────────────────────────────┐  │
│  │ 单次导出  ¥5.9             │  │
│  │ 获得 1 次 PDF 导出机会      │  │
│  └────────────────────────────┘  │
│                                  │
│  ┌────────────────────────────┐  │
│  │ 开通会员  查看更多方案 →   │  │
│  │ 无限次导出 + 全部权益      │  │
│  └────────────────────────────┘  │
└──────────────────────────────────┘
```

### 5.4 支付完成回调

```typescript
// 订阅会员支付成功
onSuccess() → appUser.tier = 'member'
            → appUser.memberUntil = 根据方案计算到期日
            → appUser.remainingPdfExports = 999
            → 刷新页面后从数据库读取（需修复持久化）

// 单次导出支付成功
onSuccess() → appUser.remainingPdfExports += 1
            → tier 不变，仍为 'free'
```

## 6. UI/UX 交互规范

### 6.1 定价页（PricingPage）

**布局：**
- 顶部：标题 + 副标题（会员用户显示"您当前已是尊享会员"）

**方案卡片：**
- 突出显示「最受欢迎」方案（月卡）—— 蓝色边框 + 顶部标签
- 每个卡片展示：名称、价格、日均价、目标用户、权益列表、选择按钮
- 年卡/季卡在卡片上显示"🔥 省更多"标签

**新增单次导出方案展示：**
- 在方案列表顶部或侧边以独立卡片展示
- 标签："按需付费"
- 特征：不与订阅方案并列对比，强调"即买即用"

### 6.2 升级弹窗（UpgradeModal）

**触发方式：** 功能受限时自动弹出（参见 5.2 节）

**布局：**
- 顶部：皇冠图标 + 标题 + 触发原因标签
- 中部：三个一行的方案卡片（grid cols-3）
- 底部：核心权益横幅 + 选择按钮 + 协议链接

**交互：**
- 点击卡片选中方案（蓝色边框高亮）
- "立即订阅"按钮跳转至支付步骤
- 支付步骤展示模拟二维码 + "已完成支付"确认按钮
- 成功后弹出 success 步骤 → 自动关闭

### 6.3 导出购买弹窗（ExportModal，新增组件）

**触发方式：** 免费用户点击"导出 PDF"且 `remainingPdfExports === 0`

**布局：**
- 上半：两个选项按钮（单次导出 / 开通会员）
- 下半：底部说明文字"您当前没有导出次数，请选择以上方式继续"

**交互：**
- 点击"单次导出"→ 跳转单次支付（¥5.9）
- 点击"开通会员"→ 跳转定价页
- 支付成功后自动执行导出

### 6.4 预览水印

**当前问题：** `ResumePreview.tsx` 第 181-187 行在非会员预览时叠加水印 DOM。

**规范：**
- 预览是编辑体验的一部分，**不应设限**
- 水印只应在导出的 PDF 中出现（由 PDF 生成层控制）
- **移除** `ResumePreview.tsx` 中的 watermark DOM 层
- **导出限制通过次数门禁实现，而非视觉遮挡**
